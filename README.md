# Étoiles filantes

Un petit jeu d'arcade en HTML / CSS / JS, sans dépendance.

Pilote la fusée 🚀, attrape les étoiles ⭐ (+1) et évite les météorites ☄️ (−1 vie). Trois vies, ça accélère avec le temps.

**Contrôles** : souris, doigt (mobile) ou flèches ← → / A D.

## Jouer en local

Ouvre `index.html` dans un navigateur.

## Publier sur GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root.
